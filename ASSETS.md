# Assets

Color Tap Blitz is an offline-first game with a code-driven visual system rather than large binary media.

| Asset | Source | Role |
|---|---|---|
| Neon midnight palette | `theme.config.js` and screen styles | Creates a focused, high-energy reaction-lab atmosphere |
| Violet, Aqua, Coral, Yellow swatches | `lib/game.ts` | Core gameplay colors and accessible text-labelled response options |
| Lightning mark and bolt tab icon | Unicode glyph plus Material Icons | Lightweight brand signal for a fast reflex game |
| Expo template icon and splash | Existing scaffold | Packaging fallback until a custom store icon is commissioned |

No gameplay image or audio asset is required for this version, keeping the build lightweight and usable without a network connection.
